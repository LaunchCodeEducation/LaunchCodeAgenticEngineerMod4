# Reference Index

Last updated: 2026-09-17

## Current status

MarketRadar currently has no indexed reference documents. This index exists so
that the reference layer is discoverable even when empty — a future session
should check here first rather than assuming references exist or searching
the rest of the repository for background material.

## When to add a reference document

Add an entry here when a larger historical, design, or investigation document
becomes useful for occasional lookup but does not need to be loaded into every
session — for example, a past pull request description explaining why a major
change was made, a longer architecture write-up for a specific feature, or
technical investigation notes about scraping approaches and their production
limitations. Documents that describe current feature state belong in project
memory instead, and stable rules that apply to every session belong in
knowledge files, not here.

## Retrieval rule

Reference documents are retrieved on demand, not automatically loaded at
session start. When a task calls for background material, consult this index
first and read only the specific document relevant to that task, rather than
loading the entire reference directory into context.
